# libcivk

Kotlin driver for Icom CI-V (CAT) rigs over the Android USB host (CDC-ACM) or TCP: full rig control plus the scope-capable models' spectrum waveform (IC-7300/7610/705/9700/905/R8600/7851).

Canonical repository: <https://github.com/nrolabs/libcivk>
Maintained by Isak — PU3IAR.

Shipped inside [iSDR Drivers](https://github.com/nrolabs/isdr-drivers) as a
submodule; the byte-exact protocol tests live there, next to the other
driver suites.
